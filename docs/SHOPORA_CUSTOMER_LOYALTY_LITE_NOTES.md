# ShopOra Customer Loyalty Lite Notes

This is a frontend-only polish layer for the customer account and storefront experience.

## What it is

- Display copy and readiness cues for saved favorites, order history, recent views, and profile/shipping readiness
- A lightweight member-feeling layer that makes ShopOra feel more like a real department-store account experience
- Honest UI guidance only; no rewards engine is implied

## What it is not

- No points balance
- No rewards redemption system
- No store credit
- No discount wallet
- No loyalty database schema

## Possible future upgrades

- Real loyalty points table
- Reward thresholds
- Promo-code tie-ins
- Email or member campaigns
- Personalized offers

## Current guardrails

- No checkout submission changes
- No order creation changes
- No Stripe changes
- No Netlify Functions or env handling changes
- No Supabase RLS changes
- No push, deploy, or merge performed
